# 《人工智能与组织理论》课程平台设计系统

版本：`v0.1`  
日期：2026-08-14  
状态：开发前基线

## 1. 使用方法

本文件是课程平台的全局视觉规范。开发页面前，先检查 `pages/<page-name>.md`：

- 有页面规范时，局部规范覆盖本文件的对应条目。
- 没有页面规范时，直接使用本文件。
- 新增颜色、字号、间距或动效前，先判断现有 token 是否够用。

本系统结合了平台总体方案、`frontend-design`、`ui-ux-pro-max` 和 `video-shotcraft` 的规则。自动检索曾把项目归为“AI 聊天产品 + App Store 下载页”，这与课程的学术定位和 Web 平台形态不符，本版未采用该建议。

## 2. 设计方向

核心方向：**学术编辑部 × 组织系统图谱**。

页面要同时容纳两类活动：安静地阅读理论，清楚地观察组织关系、学习步骤和证据流动。主视觉可以使用编辑网格、页码、批注、索引和节点连线，但不把页面做成仿旧书或科幻控制台。

用户应当记住两个特征：

1. 纸张感的阅读界面，但文字清晰、操作现代。
2. 组织关系不只靠文字解释，还通过节点、连线、时间轴和证据标记呈现。

### 3.2 使用约束

- 主界面以纸张色、墨色和松石色为主；朱砂色一屏内只强调少数关键动作。
- 不使用蓝紫渐变表示“AI”，也不用发光边框区分智能体。
- 状态不只靠颜色区分，必须同时使用文字、图标或纹理。
- 正文和背景的对比度不低于 `4.5:1`，大字不低于 `3:1`。

## 4. 字体与排版

### 4.1 字体栈

```css
:root {
  --font-display: "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", serif;
  --font-body: "Source Han Sans SC", "Noto Sans CJK SC", "PingFang SC", sans-serif;
  --font-latin-serif: "Newsreader", "Iowan Old Style", serif;
  --font-mono: "IBM Plex Mono", "SFMono-Regular", monospace;
}
```

- 展示标题和课程长文标题使用思源宋体类字体。
- 导航、表单、表格、按钮和智能体对话使用思源黑体类字体。
- 英文大标题可用 Newsreader，但不得用它替代中文字体。
- 引用键、版本号、模型名和代码使用等宽字体。

### 4.2 层级

| 层级 | 大小 | 行高 | 建议字重 |
|---|---:|---:|---:|
| 展示标题 | `clamp(48px, 7vw, 104px)` | `0.98` | `600` |
| H1 | `clamp(36px, 5vw, 64px)` | `1.08` | `600` |
| H2 | `clamp(28px, 3vw, 40px)` | `1.2` | `600` |
| H3 | `22px` | `1.35` | `600` |
| 正文 | `18px` | `1.75` | `400` |
| UI 正文 | `16px` | `1.55` | `400` |
| 辅助文字 | `14px` | `1.5` | `400` |
| 标签 | `12px` | `1.4` | `600` |

长文每行控制在 `32–40` 个汉字，或约 `65–75` 个英文字符。正文最小字号为 `16px`。标题字距要克制，不对中文大幅增加字距。

## 5. 栅格与间距

桌面端使用 12 栏网格，边距 `clamp(24px, 4vw, 72px)`，栏距 `24px`。学术长文不强行铺满网格，正文占 6–8 栏，留给章节导航、引用和批注 2–3 栏。

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;
  --space-12: 48px;
  --space-16: 64px;
  --space-24: 96px;
  --radius-sm: 4px;
  --radius-md: 10px;
  --radius-lg: 18px;
}
```

不随意使用胶囊形状。标签可以是胶囊，卡片、表单和导航保持较小圆角。

## 6. 版式结构

### 6.1 公开课程站

- 首页不罗列全部功能，依次回答：课程研究什么、学生怎么学、本学期怎么走、从哪里进入。
- 首屏使用大标题、一条课程判断和一张可读的组织关系图，不使用巨大机器人头像。
- 课程路径使用横向时间轴或竖向索引，不做成等大功能卡片墙。

### 6.2 教材与知识库

- 章节目录、正文、引用与智能体伴读可三栏并置，移动端按“正文 → 引用 → 伴读”顺序展开。
- 引用必须显示来源、年份、可见范围和对应段落；默认不折叠成一个无法追溯的“参考资料”标签。
- 概念之间的关系用线和方向呈现，连线要有文字标注，不做纯装饰网络。

### 6.3 学习、教学与研究工作台

- 学生首页首先显示本周任务、待修改作品和已收到的反馈，不从功能菜单开始。
- 教师端保留表格、筛选和批量操作；聊天框只用于探索、起草和解释。
- 研究项目用一条可检查的证据链呈现：问题 → 来源 → 主张 → 设计 → 分析 → 反例 → 审核。

## 7. 组件

### 7.1 按钮

- 主按钮：松石底、浅纸色文字，高度不低于 `44px`。
- 次按钮：透明底、松石色边框和文字。
- 高风险按钮：只在确认区域使用朱砂或错误色，不与普通主按钮并列争夺注意力。
- 按钮文案使用动作，如“查看课程大纲”“提交修订”，少用“立即开启”。

### 7.2 卡片与容器

- 只有可点击的容器才显示指针和 hover 状态。
- hover 主要改变边线、底色或阴影，不用缩放造成布局抖动。
- 阴影只区分层级，默认卡片优先用边线而不是浓重投影。

### 7.3 智能体

- 回答必须将“课程资料”“教师确认观点”和“模型推断”分开。
- 流式输出使用稳定的文字容器，不让页面高度和引用区反复跳动。
- 正在思考、检索、生成引用和等待教师复核是不同状态，需要使用不同文案。
- 智能体头像不承担信息层级；角色名、职责和权限边界始终可见。

### 7.4 图标、表格与表单

- 图标统一使用 Lucide 或同一套线性 SVG，不用 emoji 代替界面图标。
- 表格在小屏上可水平滚动或转为字段卡，但字段标签不能丢失。
- 表单输入项有可见 label；placeholder 只提供示例，不替代 label。
- 异步提交后按钮显示加载状态并禁用重复提交，错误信息靠近对应字段。

## 8. 动效与视频

网页微交互时长为 `150–300ms`，入场使用 ease-out，离场使用 ease-in。只动画 `transform` 和 `opacity` 等低开销属性。

每个视图同时运动的主要元素不超过 2 个。不使用滚动劫持，视差只用于非必要装饰，并为 `prefers-reduced-motion: reduce` 提供无动效方案。

课程网站宣传片、功能演示和智能体引导视频必须使用 `video-shotcraft`。影片从上述颜色、字体、网格和材质出发，只借用镜头卡的运动语法，不照搬模板的视觉皮肤。

## 9. 响应式与可访问性

- 固定测试宽度：`320px`、`375px`、`414px`、`768px`、`1024px`、`1440px`。
- 触控目标不小于 `44 × 44px`，主要交互不依赖 hover。
- Tab 顺序与视觉顺序一致，所有交互元素都有可见 focus ring。
- 图片提供 alt 文本，图表同时提供表格或文字摘要。
- 异步内容预留空间，避免加载时发生布局跳动。
- 移动端不得出现整页水平滚动。

## 10. 禁用模式

- 蓝紫渐变、玻璃聊天框、发光机器人头像组成的通用 AI 界面。
- 每个功能都塞进等大圆角卡片的布局。
- 与 Web 平台无关的应用商店评分、手机壳、下载按钮和二维码。
- 把所有操作改成对话，或让智能体遮住课程内容。
- 没有信息作用的滚动数字、环形粒子、扫描线和连续闪光。
- 低对比度灰字、不可见 focus 状态、仅用颜色区分状态。
