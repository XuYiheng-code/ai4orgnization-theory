# 《人工智能与组织理论》课程智能体平台

本项目面向本科生，建设一套同时服务课程公开传播、课堂学习和师生互动的智能体平台。当前已具备可运行的公开课程站、微信小程序与 OpenMAIC 学习平台，并在生产服务器上部署；仓库保存课程内容、产品方案、知识库规范、品牌材料与全部源代码。

平台暂分为四个部分：

- 公开课程站：课程首页、课程大纲、在线教材、团队介绍、课程动态和公开问答。
- 教学工作台：班级、作业、项目、反馈、学习记录，以及教师审核后的成绩。
- 社会科学研究工作台：研究问题、来源与证据、假设、研究设计、分析产物、仿真实验、审核和可复核研究包。
- 智能体与知识服务：教师数字分身、组织理论导师、AI 素养导师、作业教练、评审智能体和项目协作智能体。

## 快速开始

仓库包含三个可独立运行的应用，位于 `apps/`：

| 应用 | 技术栈 | 运行方式 | 默认端口 |
| --- | --- | --- | --- |
| `course-platform-prototype` | Python 3.11（标准库 HTTP 服务） | `python3 server.py` | 8765 |
| `openmaic` | Next.js 14（Node 22） | `pnpm install && pnpm dev` | 3100 |
| `course-mini-program` | 微信原生小程序 | 微信开发者工具打开本目录 | — |

环境要求：
- 课程站 / OpenMAIC 需要大模型密钥：分别将 `infra/course-platform.env.example` 复制为 `apps/course-platform-prototype/.env.local`、`apps/openmaic/.env.example` 复制为 `apps/openmaic/.env.local`，填入 `DASHSCOPE_API_KEY`。密钥仅从运行环境注入，**不写入仓库**。
- 小程序需在微信开发者工具中填入 AppID `wx23b18a4b1624ec53`（已配置）；登录、问答、语音转写等功能依赖上面的课程站后端。

媒体与素材：
- 课程宣传片、章节视频、校徽与教师照片已随仓库提供于 `apps/course-platform-prototype/assets/`，页面直接引用。
- 更大的品牌素材包与课程参考文献 PDF **未入库**（体积较大且含版权复核项），部署时另行同步；动画帧 dump（`assets/_frames/`）同样不入库。

## 设计纪律

1. 课程内容先于页面。每个功能都要能指向一个明确的教学活动。
2. 学生看到的回答必须能追溯到教材、课程资料或标注过的外部来源。
3. AI 可以提供形成性反馈，不能独立决定正式成绩。
4. 公开内容与学生数据分区管理。对外开放不等于开放班级、作业和对话记录。
5. 先做模块化单体，等真实使用量和维护压力出现后再拆服务。
6. 现实证据、模拟证据和派生分析分开保存；仿真结果不能单独证明现实因果关系。
