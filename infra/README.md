# 课程网站发布与运维

本目录保存《人工智能与组织管理》课程网站的部署文件。当前只完成本地准备，不连接服务器，也不修改域名解析。

## 已知上线条件

- ICP 备案已通过，备案号以阿里云备案控制台显示为准；
- 生产服务器为阿里云 ECS，Alibaba Cloud Linux 3，杭州地域；
- 当前 ECS 公网 IP 与备案详情页显示的实例 IP 不同。阿里云官方说明：同一阿里云接入商内更换非经营性网站服务器通常无需重新备案，但发布前仍应在备案控制台确认备案状态正常；
- 域名拼写必须从域名控制台复制，不能根据截图手输。截图中的 `orgnization` 可能是已注册拼写；
- 网站首页需要展示 ICP 备案号并链接工信部备案系统；网站开通后 30 日内办理公安联网备案，审核通过后再悬挂公安备案号。

## 推荐结构

```text
浏览器
  └─ HTTPS 443
      └─ Nginx
          └─ 127.0.0.1:8765
              └─ Python 课程服务
                  ├─ 课程页面
                  ├─ 知识库文件
                  └─ 千问 API（密钥仅保存在服务器环境文件）
```

Nginx 负责域名、HTTPS、静态缓存和访问入口；Python 服务只监听本机，不直接暴露 8765 端口。

## 发布目录

```text
/srv/ai4organization-theory/
├── current -> releases/20260813-230000
├── releases/
│   └── 20260813-230000/
│       ├── apps/course-platform-prototype/
│       └── 课程的参考文献/
└── shared/
    └── course-platform.env
```

每次发布都创建新版本目录，验收通过后再切换 `current`。旧版本至少保留两个，出现问题时把软链接切回上一版即可。

## 文件说明

- `DEPLOYMENT.md`：从本地初版到正式开放的完整步骤；
- `nginx/course-site.conf`：Nginx 配置模板；
- `systemd/course-platform.service`：后台服务模板；
- `course-platform.env.example`：服务器环境变量样例；
- `scripts/package-release.sh`：在本地生成待上传压缩包；
- `scripts/verify-release.sh`：部署后在服务器本机执行的检查。

## 当前不要做的事

- 不要把域名提前解析到尚未配置好的服务器；
- 不要在安全组中开放 8765、数据库或管理端口；
- 不要把 API Key、SSH 私钥或学生数据放进发布包；
- 不要公开整个参考文献目录。当前目录约 193 MB，且可能含受版权保护的教材与论文；
- 不要把现在的“教学平台”当作真实作业系统，它的数据只保存在浏览器 `localStorage`，没有账号、权限、数据库和备份。
