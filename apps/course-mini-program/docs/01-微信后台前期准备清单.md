# 微信后台前期准备清单

更新日期：2026-08-13

后台菜单名称可能随微信公众平台调整，实际操作时以页面显示为准。下面只列现在可以准备的事项，不代替平台审核结论。

## 一、主体与账号

- [ ] 确认由学校、学院还是项目团队作为小程序主体；
- [ ] 确认主体有权使用课程名称、校名校徽、教师姓名和肖像；
- [ ] 注册小程序账号并保存 AppID；
- [ ] 设定管理员与至少一名备份运营人员；
- [ ] 建立管理员变更、密钥保管和代码发布记录；
- [ ] 确认服务类目是否覆盖在线教育、课程学习和 AI 问答；
- [ ] 提前准备类目可能要求的资质材料。

主体选择会影响备案、认证、类目和后续人员交接。课程团队应先确定责任主体，再填后台资料。

## 二、名称与基础资料

- [ ] 小程序名称；
- [ ] 简称；
- [ ] 头像与 144 × 144 像素图标源文件；
- [ ] 简介，说明课程对象与主要功能；
- [ ] 服务类目；
- [ ] 客服或问题反馈联系方式；
- [ ] 关于课程、教师和建设团队的确认稿。

暂定名称可以使用“人工智能与组织管理”。如果课程正式名称仍可能调整，先不要频繁提交名称审核。

## 三、备案与域名

- [ ] 确认小程序备案负责人；
- [ ] 准备主体证件、负责人信息和真实性核验材料；
- [ ] 购买或确认 API 域名；
- [ ] 完成域名 ICP 备案与 HTTPS 证书配置；
- [ ] 在后台配置 request 合法域名；
- [ ] 配置文件上传、下载域名；
- [ ] 如采用流式 WebSocket，配置 wss 域名；
- [ ] 正式发布前关闭开发工具的“不校验合法域名”选项。

小程序网络请求只能访问后台登记的通讯域名。正式域名不能使用 `localhost` 或裸 IP，生产环境使用 HTTPS；WebSocket 使用 WSS。

## 四、隐私与用户权利

- [ ] 列出实际收集的信息：微信身份标识、姓名或学号、班级、对话、作业文件、反馈和操作日志；
- [ ] 分别写明处理目的、保存期限、访问人员和删除方式；
- [ ] 确认第三方模型服务会收到哪些数据；
- [ ] 明确不把作业、成绩和班级对话用于公开模型训练；
- [ ] 准备小程序隐私保护指引与用户协议；
- [ ] 设计授权前说明、拒绝后的可用功能和再次授权路径；
- [ ] 提供注销、删除、导出和更正申请渠道；
- [ ] 为未成年人或在校生数据处理确认校方规则。

隐私文本要和代码行为一致。以后新增文件上传、语音、定位或手机号功能时，先更新数据清单和隐私说明，再提审代码。

## 五、开发与发布权限

- [ ] 添加开发者、体验者和项目成员；
- [ ] 确认谁可以上传代码、设置体验版和提交审核；
- [ ] 把 AppSecret 放入服务端密钥管理，不通过聊天或文档明文传递；
- [ ] 建立开发、测试、生产三套环境变量；
- [ ] 准备体验版测试名单；
- [ ] 记录每次上传版本、审核说明和回滚版本。

## 六、上线前必须验收

- [ ] A 学生不能读取 B 学生的对话、草稿和作业；
- [ ] A 班级不能检索 B 班级的私有资料；
- [ ] 退出登录后，本机不展示上一个账号的私有缓存；
- [ ] AI 回答显示来源，资料不足时拒答；
- [ ] 模型故障时，教材和已有作业仍可查看；
- [ ] 文件上传校验类型、大小和恶意内容；
- [ ] 教师确认前，AI 反馈不显示为正式成绩；
- [ ] 删除或注销申请可追踪处理；
- [ ] 隐私说明与实际接口调用一致；
- [ ] 在真机、弱网和不同屏幕尺寸上走完整流程。
