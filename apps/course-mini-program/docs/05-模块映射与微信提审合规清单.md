## 一、网站模块 ↔ 小程序底部按键映射（是否"每个模块都有底部按键"）

结论：**网站 5 个主要功能入口（首页 / 课程大纲 / 课程教材 / 知识广场 / 关于）全部能从小程序底部 tab 进入；问答为小程序原生增强模块；教学平台（OpenMAIC）统一不在小程序内提供。**

| 网站模块 | 网站入口 | 小程序底部 tab | 小程序承载页（含子页） | 从 tab 可达性 | 内容/数据来源 |
|---|---|---|---|---|---|
| 课程首页 | index.html | **首页** | `pages/home/index` | tab 直达 | 静态镜像（与网站一致） |
| 16 周课程大纲 | syllabus.html | **大纲** | `pages/syllabus/index` | tab 直达；周次手风琴展开 | 静态镜像 |
| 三条课程教材线 | textbooks.html | **教材** | `pages/textbooks/index` | tab 直达 | 静态镜像 |
| 知识广场（参考文献 / 项目课程平台） | knowledge.html | **知识** | `pages/knowledge/index` → `pages/webview/index` | tab 直达；两入口 `navigateTo` web-view | 网站页（web-view） |
| 课程智能问答 | 小程序原生 | **问答** | `pages/ask/index` | tab 直达 | 课程大纲/教材/知识库 + LLM API |
| 关于课程 | about.html | **我的** | `pages/about/index`（我的 → 关于课程） | 我的 → 关于课程 | 静态镜像 |

底部 6 个 tab：首页 / 大纲 / 教材 / 知识 / 问答 / 我的（`app.json` → `tabBar.list`）。
非 tab 页（参考文献 web-view、项目课程平台 web-view、关于课程、登录、隐私）均从某个 tab 页点击进入，**没有悬空、没有死链**。

> 未在小程序提供（留在网站端）：教学平台 / OpenMAIC 编辑器、作业提交与反馈、复杂教师后台、公开文件批量下载、知识库批量维护。

## 二、登录与信息采集的微信合规性（已完成）

微信对"先授权再采集"有硬性要求。本轮已落实以下改造，均符合微信官方规范：

| 改造项 | 实现位置 | 说明 |
|---|---|---|
| 启用隐私校验开关 | `app.json` 增加 `"__usePrivacyCheck__": true` | 微信隐私接口的开关 |
| 隐私政策页 | 新增 `pages/privacy/index` | 完整《隐私保护指引》，列明收集项（code/openid、可选展示名）、用途、共享范围、用户权利、未成年人、联系方式 |
| 隐私授权弹窗 | 新增 `components/privacy-modal` + `utils/privacy.js` | 登录前弹出，含"查看完整指引"与"同意并继续" |
| 登录前置授权 | `pages/login/index.js` | 点"登录"时若未授权 → 先弹隐私授权，同意后才发起 `wx.login` |
| 全局隐私拦截 | `app.js` 注册 `wx.onNeedPrivacyAuthorize` | 任何隐私相关 API 被调用时自动走授权，防御性兜底 |
| 登录方式 | `services/auth.js` → `loginWithWeChat` | 仅用 `wx.login()` 取 code，由服务端换 openid/session_key；**前端不碰 AppSecret、session_key** |
| 公开内容免登录 | 首页/大纲/教材/知识/问答 五个 tab | 浏览公开课程内容、体验课程问答不要求登录；仅"我的"等涉及账号的功能要求登录 |

要点：采集 openid 之前必须先经用户同意隐私指引；不强制登录即可看公开内容——这两点直接关系能否过审。

## 三、你必须执行的微信后台动作（我无法代点你的账号）

以下动作需在 [微信公众平台](https://mp.weixin.qq.com) 网页端完成，是过审前置条件：

1. **【最紧急】重置已泄露的 AppSecret**
   你此前在对话中明文发过 `secret key`。按微信规则视为泄露，必须：
   开发 → 开发管理 → 开发设置 → 小程序 AppSecret → **重置**；
   新 key 只写入服务端环境变量/Keychain，**绝不进小程序代码、Git、聊天、文档**。

2. **配置《隐私保护指引》**
   微信公众平台 → 设置 → 用户隐私保护 → 隐私保护指引；
   指引文本须与本应用实际调用一致（见第二节：仅 code/openid、可选展示名、语音/图片/文档用于问答）。
   未配置则 `wx.requirePrivacyAuthorize` 在生产环境报错，且**审核必拒**。

3. **服务器域名**
   开发 → 开发设置 → 服务器域名：
   - request 合法域名：`https://www.ai4orgnization-theory.cn`
   - uploadFile / downloadFile 合法域名：同上（问答图片/文档上传需用）
   - **业务域名**：需将 `www.ai4orgnization-theory.cn` 加入业务域名（参考文献、项目课程平台以 `<web-view>` 加载该域下页面）。按微信要求下载校验文件放到域名根目录完成校验。
   - **教学平台 / studio 子域不再配置**：OpenMAIC 不在小程序内使用。

4. **类目与资质**
   本应用属"教育"类。确认小程序类目选择"教育 > 在线课程/教育信息服务"等匹配项；
   若涉及付费/证书，按微信要求补充对应资质材料。

5. **注销 / 删除 / 导出渠道**
   审核会看用户数据权利是否可行使。本应用已在"我的"页提供：退出登录、隐私说明页（含注销/导出申请方式）。
   正式上线前需确保服务端真的实现了"注销即删数据"与"导出"接口。
