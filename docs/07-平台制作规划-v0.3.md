# 《人工智能与组织理论》课程平台制作规划

版本：`v0.3`  
日期：2026-08-12  
状态：前端概念验证阶段

## 一、本轮决定

平台一级导航确定为：首页、课程大纲、课程教材、知识库、教学平台、关于。

公开站负责课程介绍、内容阅读和知识发现；教学平台负责身份、班级、作业、反馈和教师确认。智能体不单独占一个入口，而是出现在教材伴读、知识问答、作业教练和教师工作台中。这样可以让每个智能体对应一个清楚的教学动作。

课程教材分成三条内容线：

1. 《人工智能与公共组织》：随 16 周课程逐步编写；
2. 人工智能基础素养：复用并改编现有 AI 素养培训中的 D1—D5 能力框架；
3. AI 实操指南：把现有工具教程、案例和练习整理为可操作的短章节。

## 二、六个栏目各自解决什么问题

| 栏目 | 首要用户 | 核心内容 | 首期完成标准 |
|---|---|---|---|
| 首页 | 访客、学生 | 课程定位、四阶段结构、学习方式、入口 | 访客能在 1 分钟内说清课程研究什么、怎样学 |
| 课程大纲 | 学生、教师 | 16 周安排、90 分钟课堂结构、考核、AI 使用规则 | 周次与课程材料可以逐步补充，不改页面结构 |
| 课程教材 | 所有用户 | 三条教材线、章节、版本、相关阅读 | 至少完成一个可连续阅读的样板单元 |
| 知识库 | 学生、研究者 | 组织学文献、理论概念、来源、课程问题 | 每条公开内容能追到文件或正式来源 |
| 教学平台 | 学生、教师、助教 | 登录、班级、作业、提交、反馈、成绩确认 | 一个测试班级走通两次提交与一次教师确认 |
| 关于 | 访客、合作方 | 项目说明、建设原则、团队职责、联系方式 | 不虚构团队信息，未确认项明确标注 |

## 三、产品边界

公开内容和教学数据必须分区。课程大纲、公开教材和公开知识条目允许匿名阅读；班级名单、提交、成绩、对话和教师私有材料必须登录，并按班级隔离。前端原型只模拟流程，演示提交保存在浏览器本地，不等于数据库已经建成。

正式系统沿用已经提出的模块化单体方案：Next.js 负责公开站与工作台，FastAPI 承载业务接口和智能体运行时，PostgreSQL + pgvector 保存业务数据和检索索引，文件进入 S3 兼容对象存储。模型意见只能作为形成性反馈或教师参考，正式成绩由教师确认。

## 四、分期建设

### 阶段 0：内容与原型对齐

- 确认课程正式名称、三项学习成果和样板单元；
- 完成六个栏目的信息架构与本地前端；
- 整理三条教材线的内容清单；
- 从现有文献中选出首批公开知识条目；
- 用原型走查学生登录、阅读、提交、修改和教师复核。

退出条件：课程团队认可样板单元，五名目标用户能在原型中完成核心任务。

### 阶段 1：公开课程站

- 建立内容源与版本发布流程；
- 上线首页、大纲、教材、知识库和关于；
- 加入站内搜索、移动端适配、打印与基础 SEO；
- 课程导航问答只连接公开知识库，并显示引用来源。

退出条件：访客无需登录即可完成“了解课程—找到样章—定位文献—查看来源”。

### 阶段 2：教学平台 MVP

- 建立账户、角色、班级和课程码；
- 支持作业发布、文本与文件提交、版本记录；
- 加入作业教练、量规反馈和教师确认；
- 完成权限测试、备份恢复与操作审计。

退出条件：两个测试班级互相不可见；一份作业完成两次提交，教师确认最终反馈。

### 阶段 3：知识与智能体

- 建设组织理论与 AI 素养两个知识域；
- 建立不少于 30 个课程问题的初始评测集；
- 上线组织理论导师、AI 素养导师、标准评审和反例评审；
- 保存知识库版本、模型版本、引用和人工修改记录。

退出条件：来源支持率、拒答正确率达到课程团队冻结的验收线，不出现捏造来源。

### 阶段 4：真实教学与扩展

- 用一个真实班级运行完整教学循环；
- 根据问答、提交和教师工作量调整界面与量规；
- 再评估研究工作台、仿真实验、数字人和跨课程复用；
- 真实运行通过后，再讨论数字公共治理专业培养平台。

## 五、近期工作包

| 工作包 | 下一项可交付成果 | 依赖 |
|---|---|---|
| 课程设计 | 补齐 16 周主题、阅读与产出 | 课程团队确认四阶段逻辑 |
| 教材建设 | 选定一个样板单元并写出两节样章 | 确认教材主编与审核方式 |
| AI 素养 | 把 D1—D5 映射到课程周次和练习 | 现有培训内容授权与改编范围 |
| 知识库 | 选 20 个概念、30 个问题、首批文献 | 版权与公开范围确认 |
| 教学平台 | 冻结学生端与教师端核心流程 | 成绩、AI 使用和数据规则 |
| 品牌与前端 | 确认“组织研究观测站”视觉方向 | 课程名称与主标识确认 |
| 技术 | 数据模型草案、测试环境、部署清单 | 服务器、域名、模型预算 |

## 六、本地原型说明

本轮原型采用单文件 HTML，实现六个栏目、响应式布局、知识库筛选、课程阶段切换和教学平台演示。页面可以断网双击打开。登录和作业提交只在浏览器本地模拟；尚未实现真实账户、PostgreSQL、对象存储、模型调用、邮件通知和权限隔离。这些功能进入阶段 2 后开发。
