# 待确认问题

这些问题会改变课程内容、数据模型或开发范围。当前方案已经给出暂定处理，课程团队可以按编号直接回复。

| 编号 | 需要确认的问题 | 当前暂定处理 | 影响 |
|---|---|---|---|
| Q01 | 正式课程名称是《人工智能与组织理论》还是《人工智能与组织管理》？ | 采用《人工智能与组织理论》 | 域名、Logo、页面标题、教材封面 |
| Q02 | 首次开课时间、总周数、班级人数和专业构成？ | 16 周，本科生，一个班级 | 容量、教学节奏、评测样本 |
| Q03 | 课程最重要的三项学习成果是什么？ | 理论解释、智能体设计、责任判断 | 大纲、作业、智能体行为 |
| Q04 | 现有大纲、教材、讲义、案例和作业放在哪里？ | 尚未进入仓库 | 内容迁移、知识库范围 |
| Q05 | 哪些教师观点可以用于数字分身？是否有授权语料？ | 只使用课程团队确认的公开语料 | 人设、拒答规则、署名 |
| Q06 | 正式成绩的构成和教师复核方式？ | AI 只给建议，教师确认 | 作业流程、审计、工作量 |
| Q07 | 学生是否允许用 AI 起草作业？需要怎样披露？ | 允许使用，但提交过程记录和反思 | AI 使用规则、诚信设计 |
| Q08 | 平台是否只服务一门课，还是同时服务公共组织 AI 培训？ | 先服务本科课程，内容层预留复用 | 多租户、导航、品牌 |
| Q09 | 云服务器的地区、配置、操作系统和数据库方案？ | 单台 Linux 服务器 + Docker Compose | 部署、备案、备份 |
| Q10 | 计划使用哪些模型，月度预算多少？ | 通过模型网关适配，尚未锁定供应商 | 成本、速度、数据边界 |
| Q11 | 是否允许公开学生优秀作品？ | 默认不公开，单独征得授权 | 作品展厅、隐私、传播 |
| Q12 | 数字 IP 希望偏教师形象、抽象角色还是原创生物？ | 原创主 IP，不直接复制教师形象 | 设计周期、肖像风险、传播 |
| Q13 | 课程团队中谁负责内容、教学运行、产品、技术和品牌？ | 尚未指定 | 需求确认、发布权限、维护 |
| Q14 | 现有“经济金融智能体设计”“数字鲜笋营”有哪些可复用资料或代码？ | 先做清单，再逐项判断许可与适配 | 进度、技术选型、授权 |
| Q15 | 谁可以修改公开教材，内容如何审核和发布？ | 仓库源码是准本，教师工作台只配置班级使用方式 | 内容版本、CMS、权限 |
| Q16 | 研究工作台是本课程必修项目，还是先作为选修实验？ | 纳入一个样板单元，首轮受控试用 | 课时、考核、开发优先级 |
| Q17 | 首个现实研究与仿真研究共用什么主题？ | “AI 辅助公共服务与一线裁量” | 案例、数据、仿真环境、量规 |
| Q18 | 首期允许接入哪些研究材料和数据？ | 只用公开材料、合成材料或获准的脱敏材料 | 伦理、权限、存储、模型调用 |
| Q19 | 现实研究和仿真研究各占多少课时？ | 课程先做现实研究主线和简化仿真；专业平台再设双实验室 | 大纲、教师分工、算力预算 |
| Q20 | 何时从单门课程扩展为数字公共治理专业培养平台？ | 真实班级完成一轮研究项目后再立项 | 多课程、跨学期档案、品牌与运维 |

## 建议优先回答

开始视觉原型前确认 Q01、Q02、Q03、Q04、Q12、Q16 和 Q17。开始后端开发前确认 Q06、Q07、Q09、Q10、Q13、Q15、Q18 和 Q19。准备公开发布前确认 Q05、Q11、Q14 和 Q20。
