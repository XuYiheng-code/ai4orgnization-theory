# 《经济金融智能体设计》参考项目分析

调研日期：2026-08-07  
调研对象：[课程主页](https://ai.lingnan.top/)、[课程大纲](https://ai.lingnan.top/syllabus)、[在线教材](https://ai.lingnan.top/book/)、[教学平台介绍](https://ai.lingnan.top/platform)、[公开教学平台仓库](https://github.com/ai-lingnan/econai-agent-platform)、[Quarto 教材模板](https://github.com/ai-lingnan/quarto-book-template)

## 一、已经形成的产品结构

参考项目把公开课程主页、在线教材和登录后的教学平台分开建设，再用统一导航连接起来。

公开站包含首页、课程大纲、课程教材、研修活动、教学平台和团队信息。首页负责说明课程定位，并把用户导向大纲、教材和教学资源。站点还提供搜索、RSS、开放许可、访问统计和 AI 问答入口。

教材采用章节化在线阅读，内容按总原则、概念与方法、应用等部分组织。公开的 Quarto 模板已经提供 Markdown 章节、两套出版配置、PDF 输出和一个可选的 AI 问答浮窗。问答前端通过 SSE 接收流式回答，载荷包含问题、当前页面、标题和历史对话。

教学平台是独立的多租户应用。公开仓库显示其后端使用 FastAPI、PostgreSQL、MinIO 和 Alembic，前端使用 React、TypeScript、Vite、shadcn/ui 与 Tailwind CSS。平台设置超级管理员、教师和学生三类入口，支持班级、名单、作业、文件提交、AI 反馈、学习资源、课程分享、模型配置和数据库备份。

## 二、适合借鉴的部分

### 2.1 公开站与教学平台分区

访客不需要先登录才能看课程，学生数据也不暴露在公开站。这一边界应直接保留。我们可以使用同一个视觉系统和域名体系，但权限、数据和发布节奏要分开。

### 2.2 教材作为可计算内容

教材不是 PDF 附件，而是有章节、锚点、元数据和源码的在线内容。这使全文搜索、按页问答、版本更新和知识库同步成为可能。《人工智能与组织理论》的课程内容也应以 Markdown/MDX 或 Quarto 源文件保存。

### 2.3 教学平台本身成为课程案例

参考课程让学生在使用双 Agent 批改和 AI 助教时观察多智能体系统。我们的课程可以做得更贴题：把权限、分工、控制、协调、冲突和问责设计成可观察的组织现象，让平台同时成为“人工组织—智能体组织”的实验场。

### 2.4 教师确认关键操作

参考平台的 AI 助教可以起草作业、搜索资料和分析成绩，但教师确认后才发布。这一原则适合继续采用。结构化管理界面也应保留，不需要把所有后台操作都改成聊天。

### 2.5 开源仓库提供了可复用边界

公开平台已经展示了班级隔离、模型适配器、文件存储、数据库迁移、备份和测试目录的组织方式。后续可以参考其接口和数据模型，但不能直接复制课程文案、品牌资产或受许可限制的内容。代码是否复用需要逐项核对 AGPL-3.0 的义务。

## 三、不建议照搬的部分

### 3.1 两个 Agent 取较高分

“标准评审”和“亮点发现”适合产生不同视角，但直接取高分会混淆形成性反馈与正式评价。我们的系统应保存两者的证据与分歧，由教师或助教确认总结性评价。

### 3.2 课程首页的功能入口过多

参考站的信息很完整，但我们的首页还要承担数字 IP 和课程方法展示。如果把大纲、教材、知识库、多个智能体、教学平台和传播内容全部平铺，学生容易不知道从哪里开始。首页应优先展示“这门课研究什么”和“本周怎么学”。

### 3.3 数字人不能只做问答壳

参考站的主要辨识度来自课程品牌和内容。我们的数字 IP 需要同时进入课程角色、教材插图、实验反馈和传播素材，并说明它能否代表教师观点。否则换一张头像并不会形成独立的课程品牌。

### 3.4 不能把 AI 工具教学压过组织理论

参考课程的大纲以 Agent 工具、Skills、Git、Hooks 和应用项目为主。我们的课程可以借用操作训练方式，但课程主线要回到组织理论。每次工具操作都应对应一个组织问题，例如分工、层级、协调、控制、制度、文化、权力或责任。

## 四、对本项目的直接启发

1. 保留“公开课程站—在线教材—教学工作台”的三层结构。
2. 在线教材从第一天就使用结构化源码，不先做静态 PDF 再返工。
3. 先完成按当前教材页提问的课程导航员，再扩展教师数字分身。
4. 作业系统先支持量规、证据、反馈、修改和教师确认，晚些再加复杂多智能体编排。
5. 用组织理论设计智能体角色和协作规则，形成与经济金融课程不同的课程方法。
6. 代码、教材、课程资料、学生作品和品牌资产分别声明许可和使用范围。
